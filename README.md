# Student Performance – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Student Performance Dataset using Python. The main objective is to analyze student-related factors and understand their relationship with academic performance.

## Dataset Information
- **Dataset Name:** Student Performance
- **Total Records:** 10,000
- **Total Columns:** 6
- **Format:** CSV
- **Target Variable:** Performance Index

### Features
1. Hours Studied
2. Previous Scores
3. Extracurricular Activities
4. Sleep Hours
5. Sample Question Papers Practiced
6. Performance Index

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Importing required libraries
2. Loading the dataset

4. Checking missing values

8. Univariate analysis
9. Bivariate analysis
10. Multivariate analysis
11. Data visualization
12. Identifying key findings
13. Drawing conclusions

## Key Findings
- Previous Scores have a strong positive relationship with Performance Index.
- Hours Studied show a positive relationship with student performance.
- Sleep Hours have a weak positive correlation with performance.
- Practicing sample question papers has a weak positive correlation with performance.
- Students participating in extracurricular activities show a slightly different average Performance Index.
- The dataset contains no missing values.
- Duplicate records were identified during data cleaning.

## Visualizations
The project includes six visualizations:
- Performance Index Distribution
- Study Hours Distribution
- Previous Scores vs Performance Index
- Study Hours vs Performance Index
- Extracurricular Activities vs Performance
- Correlation Heatmap

## Conclusion
This EDA project helps identify important factors associated with student academic performance. Previous Scores and Hours Studied show the strongest positive relationships with the Performance Index. Data visualization and statistical analysis provide useful insights into the dataset.
